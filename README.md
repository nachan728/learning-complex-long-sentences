# 句间 · 考研英语长难句学习

输入 3—15 个英文单词，生成原创考研风格阅读，查看语境释义、逐段翻译与长难句分层分析，做单词填空，收藏句子并记录笔记。支持手机单列、平板横屏双栏，以及 PWA 主屏幕入口。

## 本地运行

需要 Node.js 24 或更新版本，无第三方运行依赖。

```powershell
Copy-Item .env.example .env.local
# 用编辑器打开 .env.local，配置端口等选项；密钥在登录后的“我的 API”中填写
npm start
```

打开 http://localhost:3000 。未绑定密钥时可使用固定原创演示；注册登录后在“我的 API”中绑定自己的密钥，之后可生成。收藏与笔记无需密钥。API 模型默认 `deepseek-flash`，可通过 `AI_MODEL` 修改。模型配置参考 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)。密钥只在后端使用，不会返回客户端。

```powershell
npm test
```

## 手机、平板与部署

同一 Wi-Fi 下，本机防火墙允许 3000 端口时，可以在设备上访问 `http://电脑局域网IP:3000`。电脑需保持服务运行。这用于开发体验；公网使用必须部署 HTTPS。

可用 Docker 或 Node.js 24 在支持**持久化磁盘**的服务器部署。应用监听 `0.0.0.0:$PORT`，健康检查 `/api/me`。设置环境变量：

| 变量 | 用途 |
| --- | --- |
| AI_API_KEY | 已停用，不再读取，不会作为任何账号的备用密钥 |
| AI_BASE_URL | 默认 https://api.deepseek.com |
| AI_MODEL | 默认 deepseek-flash |
| DATABASE_PATH | 如 /app/data/study.sqlite，必须位于持久化磁盘 |
| COOKIE_SECURE | HTTPS 公网部署设为 true |
| APP_ORIGIN | 公网完整来源，如 https://study.example.com，不带末尾斜杠 |
| PORT | 默认 3000 |

本应用使用 SQLite 持久化账号、会话、收藏及笔记。同一服务器部署后，多台设备登录同一账号即可同步。不要部署到文件系统短暂、只读或多副本共享不安全的无服务器环境；不要直接放到 GitHub Pages，因为它不能运行后端。GitHub 提交代码不等于已上线。

容器运行示例（通过主机环境注入密钥）：

```sh
docker build -t sentence-lab .
docker run --env-file .env.local -p 3000:3000 -v sentence-data:/app/data sentence-lab
```

域名和 HTTPS 由反向代理或托管平台配置。PWA、离线缓存与安装需要 HTTPS（localhost 除外）；iPad/iPhone 可通过 Safari 分享菜单添加到主屏幕，具体安装入口依系统而异。

## 收藏与离线

- 收藏保存原句、分析、所属短文、关联词汇与个人笔记；按原句去重，每个账号最多 2000 条。
- 提供 JSON 导出/导入，导入跳过已存在句子，保留已有笔记。中途失败会保留成功导入的部分。
- 联网登录后缓存当前账号的收藏供离线查看；离线不支持修改或生成。主动退出会清除此账号本机缓存。共享设备使用后应退出。
- 切换设备需访问同一部署网址并登录；本机数据库不会自动迁移到新服务器。
- 备份数据库时停止服务再复制整个 `data` 目录；导出的 JSON 仅为收藏备份，不包含账号密码。

## 生成与真题风格

见 [研究记录](docs/exam-style.md)。生成器使用定性句式模板，保留长短句变化、让步转折与信息压缩；并检查长度、输入词覆盖、段落翻译和分析句子是否来自文章。当前要求输入词原形完整出现，不做词形还原。句法与事实准确性不能仅凭结构校验保证，材料明确标注 AI 原创，非历年真题。

## 当前边界

账号使用 scrypt 加盐密码摘要、HttpOnly 会话 Cookie、来源检查与基础进程内限流。暂不包含邮件验证、密码重置、管理员后台和多实例部署支持。公网开放注册前应根据实际用户规模增加邮件验证、网关限流和监控。生成配额为每账号每小时 8 次，限流在进程重启后重置。用户会话有效期 30 天。

密钥放入 `.env.local` 或部署环境变量；`.env*`（示例除外）、数据库与测试运行数据均已忽略，不要提交到 GitHub。

## 每账号独立 API 密钥

登录后打开“我的 API”绑定自己的 DeepSeek 密钥。生成只使用当前登录账号的密钥；不接受请求指定其他账号，不回退到环境变量 AI_API_KEY。旧 `.env.local` 中的 AI_API_KEY 不再使用，可以自行删除该行。

密钥以 AES-256-GCM 加密存储，账号 ID 作为附加认证数据；加密主密钥位于被 Git 忽略的 data/credential-encryption.key。备份及迁移需要连同数据库一起保护该文件。服务器管理员仍有解密能力，公网必须使用 HTTPS。客户端仅显示是否绑定与末四位，不在 localStorage、收藏导出或接口响应中保存完整密钥。

数据库通过永久归属记录与唯一约束，保证同一原始密钥在此部署中只能绑定一个账号；停用删除密文，更换不释放旧归属。独立克隆部署不共享数据库，因此不能跨他人独立服务器实施全球唯一绑定，也无法阻止某人将密钥用于其他软件。绑定不调用收费接口，实际有效性在生成时验证。

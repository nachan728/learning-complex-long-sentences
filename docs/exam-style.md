# 2022—2026 英语一阅读风格研究

2026-11-06：基于公开机构或第三方整理的跨年样本定性分析；不是官方语料库，也未完成全部 20 篇的逐句频率统计。不得对外宣称已统计出某句型占比。

| 样本 | 观察 | 训练目标 |

| [2023 Text 1](https://www.yingyuzhenti.com/papers/2023-english-one/reading-text-1) 气候教育 | 长主语、延迟谓语、让步嵌套 | 识别谓语所在层次、区分引述与作者观点 |

生成策略：每篇选 2—3 类自然组合，短句推进观点，长句容纳修饰与限定。每日 180—250 词，完整篇幅 400—450 词。内容围绕社会、科技、经济、教育、文化或环境，由输入词决定主题；不照抄试题或真实报道，不虚构真实机构研究。

分析输出：原句、翻译、主干、逐层片段及其作用、指代和论证功能、易错点。程序检查结构完整和片段归属，不把词数或从句数视为学习质量的替代指标。后续可增加人工标注语料与教学质量评测。
